# Task and leakage controls

The method selects one of four supplied solutions; it neither generates an answer nor certifies every reasoning step. Inputs are the passed question bank and float32 embeddings of shape [N,4,1024]. Output is a list of N Python integers in 0..3, preserving question order. A checkpoint directory is mandatory for the learned selector.

Candidate labels are independent binary events: the unchanged official `parse_answer(candidate.text)` is non-None and equals `parse_answer(reference.answer)`. Preserve all correct candidates. Fit only train. Validation supports model selection and descriptive analysis; test is reserved for an independently executed final scorer after a recorded freeze. All question IDs are used for alignment and evidence only; inference ignores them. No external data, pretrained weights, labels from an external model, new API calls, or answer lookups.

H1: a shared regularized linear verifier over fixed whole-trace embeddings improves selection on disagreements relative to majority answer. H2: candidate-relative deviations, answer agreement and simple format features add useful information. H3: changing the candidate BCE objective to a multi-positive listwise objective changes selection quality. H4: train-only OOF-calibrated confidence predicts selected-final-answer correctness on validation. These are hypotheses, not promised outcomes.

BCE averages binary cross-entropy across all 4N candidates and preserves multiple positives. Listwise loss is mean(logsumexp(all four scores) - logsumexp(correct-candidate scores)); all-positive questions correctly contribute zero data gradient. L2 penalizes weights, not bias. A linear embedding difference from the group mean would cancel from argmax, so the enriched branch uses absolute deviations, a nonlinear relative feature, rather than claiming redundant centering as an improvement. It also contains cosine similarities, parser success, answer-group size and text-format counts. No question-specific arithmetic rules or executable candidate text are used.

All normalization statistics fit on the relevant train partition. The 80/20 screen and three OOF folds are question-grouped. The final calibrator fits selected-answer correctness from train-only OOF predictions and never changes the candidate decision. Validation is independent of calibration fitting, but reused for model selection, so reported performance remains susceptible to selection optimism.

Primary development measure: full validation selection accuracy. Prespecified diagnostic hard subset: at least two distinct non-None parsed answers. Report its denominator. Random-choice expectation is mean(number correct / 4), not necessarily 25%. Whole-trace embeddings remain in all learned methods, so neither enriched-feature ablation nor removal of explicit length features would establish that reasoning was not used.
