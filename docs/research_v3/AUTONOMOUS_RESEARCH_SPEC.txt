启动计划划分约：15%机制与baseline，45%主要模型，20%复验/融合，20%消融/稳定性；可按实际耗时重分配并记录，不占用最终交付缓冲。

循环必须真实执行：
提出一个可检验假设 → 写入注册表 → 实现 → 快速排错 → train内共同题级CV → 资源审计 → 开发错误分析 → 保留/淘汰并解释 → 选择下一项。
连续进展时继续下一轮，不因出现一个高分就立刻终止，也不因一个方法失败就结束。每轮新增2—4个有依据的配置；避免学习率、宽度、loss、特征同时乱改后无法归因。
可以先在一个固定内层pilot上短训练淘汰明显失败项。主实验表必须完成共同外折，不能只给胜出者做CV。
出现安装/显存/内存/数值问题，优先减batch、缩宽度、关闭非必要编译、改CPU兼容实现；失败2次后标记原因继续其他家族。不要修改评估器或放宽限额来“修好”。
在时间够的前提下，覆盖选择机制、MLP/优化器、至少一个候选交互家族、TabM或RealMLP后，才允许用“搜索趋于饱和”提前结束。连续3轮不同明确假设都没有超过预注册最小增量且无可执行新假设时，转入交付；不能用重复同一配置凑轮数。

七、严格比较协议：题级CV、OOF和最终validation

1. 仅在官方train内创建并保存固定3个外折。同题四候选始终同折；如存在可可靠识别的重复题，按题组一起分配。可按正例数/可解析答案种数适当分层，稀有组合合并。
2. 每个外折训练部分再划分内部早停集，所有预处理只fit内部拟合部分。外折不能既用于挑epoch又被称为独立评估。可用内部划分确定轮数，再从头在该外折完整训练部分拟合预处理并训练；最终唯一候选同样按确定轮数，从头在完整官方train上拟合预处理并训练。预处理和模型权重必须来自同一训练流程，禁止把内部checkpoint配上另行重拟合的全train scaler/PCA。validation不得参与重训。
3. 外折成绩用于方法搜索，因此属于开发证据，不能称完全无偏的泛化估计；报告选择偏差。所有模型使用共同splits和预定seed。
4. 基线参与融合也必须按该协议生成OOF。全train模型对train的预测不是OOF；旧OOF仅在分组、训练来源和early-stopping隔离确实匹配时复用。
5. 每道题保留完整4个标签。可用多正例listwise、答案组目标或逐候选BCE；不能任选一个正确候选并把其他正确候选变负例。
6. 指标：完整题级accuracy；hard固定定义为至少两个不同有效解析答案的题；唯一正确候选子集；correct/n；折间与seed波动；训练成本；资产；完整进程成本。
7. 选择优先级预先固定：资源合规 → hard表现 → 完整准确率无无法解释的退化 → 固定seed稳定性 → 更低复杂度。hard重点依据官方公开test构造，不依据test错题。
8. 胜出与基线按题做paired bootstrap差值区间，记录“多选对几题”。不要将4候选当独立样本扩大有效样本量，也不要把跨零区间包装成确定提升。
9. 最后缩减到最多2个预注册finalist后，再运行官方validation并选择。官方允许validation开发；本工作流主动限制反复探查。不要每轮看官方validation错题继续自动扩搜索。
10. 官方validation已经被历史项目使用，不能称全新未见holdout。只用它做开发确认，不fit权重/校准/fusion。若两finalist失败，按预注册规则保留旧方法或开发基线，不靠重新命名campaign重置验证预算。
11. 配置/seed选择与完整主表规则写在实验前；运行后发现合理实现错误可修复并标记受影响结果失效，不能悄悄只删差成绩。

八、方法队列：复用代码与示范，逐项验证

官方代码只提供空预测接口和评估工具，没有现成训练基线。不要编造“官方已训练baseline”。所有下列新方法在本项目上的收益均待实测。

A. 基线、解析mask、答案组和目标对齐（首先完成）
复现现有线性模型的train-CV结果。历史validation结果直接引用既有记录；确需检查环境或接口回归时，仅对不变的历史基线做一次validation复现，标为回归检查，不据此扩展搜索。新候选缩减到最多两个finalist前，不读取官方validation标签或逐题误差；开发阶段资源测量优先用train或形状匹配的合成输入。不重跑旧test。另以固定候选、有效答案多数票作为简单参照，明确平票规则；不必为填表把所有参照都拿去test。
历史模型使用[embedding,abs(embedding-同题均值),16统计]共2064维，最终仍为线性score；它已有关系信息，不能说完全没有候选关系。部分同题共享统计在纯线性argmax中相消，非线性模型有机会改变其作用。启动时核验当前代码是否仍如此。
使用官方parse_answer排除None；存在有效答案时None不可选。按官方解析值的明确等价关系合组，不改scorer或自创从test学来的容差。若正确性判断含容差导致多个数值组都被判对，使用多正例组损失，不强行假设只有一个正确组。全None采用预定义确定性回退，记录异常。
比较candidate-max、group-LSE及归一化group-LSE：
  S_a=logsumexp(s_j/tau, j in G_a)-alpha*log(|G_a|)。
先tau=1，alpha候选{0,0.5,1}，只在train内选择。group-max与有效候选max等价，仅用于实现核对。选择组后返回组内最高分候选的原始索引。
训练保留多正例listwise L=LSE(all)-LSE(correct)；可比较组CE/多正例组损失、BCE、按题平均的正负pair loss。多个正确候选不能互为负例。
在所有候选有效且alpha=0,tau=1、标签与答案组一致时，group聚合目标与候选多正例listwise可能等价，不把数学等价重写说成新算法收益。
全正例或唯一有效答案组的题可能无排序梯度。比较在有判别信息的题上归一化loss，并同步考虑正则尺度；不要把loss缩放变化误称架构提升。最终评分分母保持完整。

B. 小MLP / ResMLP / Deep Sets / 四候选attention
MLP从2064→128→64→1起步，后比较小ResMLP，宽128/256、1—2块；有限dropout/学习率/weight_decay搜索，不全排列。
Deep Sets示意：h_j=phi(e_j)，m=mean(h)，v=max(h)，score_j=rho([h_j,m,v,abs(h_j-m),h_j*m,t_j])。所有phi/rho共享，池化仅同题内。与同等容量独立MLP比较，证明候选交互是否有价值。
attention使用[batch,4,1024]→投影128维→一层2/4头注意力→共享候选head；无位置embedding作为默认，FFN约256。4个候选是4个token，不把1024维当1024token。不是大型LLM，也无需加载预训练权重。
可做训练内候选置换增强，文本、embedding、标签、组索引同步置换；推理正确还原原index。平票的确定性选择与等变性例外写清楚。

C. 优化器与权重平均：AdamW / EMA / Muon（高优先级）
来源：2026预印本Benchmarking Optimizers for MLPs in Tabular Deep Learning。
https://arxiv.org/abs/2604.15297
https://github.com/yandex-research/tabular-dl-optimizers
同一个小MLP固定结构比较AdamW、AdamW+EMA、Muon+辅助AdamW。按作者实现确认Muon适用的隐藏2D权重矩阵；输出头、bias、norm等用合适的辅助优化器，分别设参数组与学习率。不要盲抄示例里未定义变量或假设不同优化器共用同一学习率就是公平。
EMA更新顺序、decay和选择规则由train内部确定。只导出最终选中的平均权重，不把训练optimizer state装进推理包。EMA/Muon不保证收益，记录训练额外成本。
不能直接平均独立随机初始化、不同架构或不同scaler/PCA坐标的网络权重；同一训练轨迹的EMA/SWA更适合作为本项目对照。使用BN时正确处理统计，不把EMA说成新提出的方法。

D. TabM小规模参数共享集成（高优先级）

E. RealMLP-TD-S-inspired verifier（高优先级）

结构/宽度/损失改写后标为inspired adaptation，不能冒称完整复现论文。优先独立轻量实现，不为此引入整套昂贵AutoML。

G. Weaver-inspired异质融合与可选自蒸馏
NeurIPS2025论文（2026修订）：https://arxiv.org/abs/2506.18203
作者代码：https://github.com/HazyResearch/scaling-verification
只借鉴弱验证器组合思想；禁止运行其中大型judge/API/外部数据/400M预训练模型流程。候选成员来自上面仅用官方train训练的小模型和确定性输入信号。
先画OOF错误重叠表，保留2—3个有互补证据的成员。对齐有效答案组并比较等权概率平均、预注册极小权重网格和带正则小stacker；不默认未经校准的logit可直接相加。
严格fusion评估：对每个外折，成员训练、内部超参选择、校准和融合拟合均在外折训练部分完成；在该部分再做内部OOF生成stacker训练数据。外折题目不得通过任何成员训练标签间接影响其融合器。简单对全局OOF再随机切meta折，不自动构成严格嵌套评估。
最初可先用固定等权融合降低成本；无法承担嵌套学习型fusion就保留简单融合，不伪称严格OOF。最终fusion参数仅由完整train内OOF拟合。
预算允许可将自己的train-only模型集成蒸馏到一个小student。teacher不得见对应外折标签；禁止外部教师和预训练权重。硬标签＋软组分布损失在train内确定。只有实测在精度/资源上划算才保留，不为了写“蒸馏”增加流程。
置信度使用最终实际选择器的正确事件重新校准；旧argmax校准器不可无条件移用。报告Brier/ECE及样本数，risk–coverage仅分析，正式输出不能弃答。
