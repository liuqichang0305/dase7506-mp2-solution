# 这次性能研究在做什么

这是解释方法和流程的草稿，不是最终成绩单。最终方法、验证和测试数字，只能在唯一模型完成冻结、正式测试及复现后，由 `reports/research_v3/prepare_report_inputs.py` 从保存证据生成到 `reports/research_v3/understand_final_zh.md`。现在没有填写尚未发生的成绩，也不根据交叉验证推算排行榜名次。

## 从候选分数到答案组

每题有四份候选解答。旧模型把每个候选的 1,024 维 embedding、与同题平均 embedding 的绝对差、16 个统计拼成 2,064 维特征，再学习一个线性权重向量。绝对差、余弦等已经是非线性特征，因此不能把旧模型说成“完全没有关系信息”；不足是没有可学习的多层交互。

旧目标是所有候选的 log-sum-exp 减去所有正确候选的 log-sum-exp，已经正确处理多个正确候选，没有把第二个正确答案当成负例。旧推理直接取原始分数最大候选，没有硬排除解析失败，也没有合并答案相同的候选。

新选择器调用课程原始 parser。能解析且得到相同数值答案的候选属于同一组，`None` 不构成答案组。`group_max` 与 masked candidate max 数学等价。`group_lse` 合并同答案候选的分数，但相关解答不能被当成独立证据。alpha 仅比较预定的 0、0.5、1，tau 为 1；完全平分采用明确规则，全不可解析时回退索引 0、置信度为 0。这保证接口有效，不保证课程契约之外的任意输入都答对。

## 为什么比较不同网络

- MLP 学习特征之间的非线性交互；ResMLP 增加残差结构。
- Deep Sets 和 Attention 学习同题候选上下文，不加入候选位置编码。
- TabM 使用共享矩阵和成员适配器；每个成员独立计算损失，预测时平均答案组概率，不能先平均 logits 冒充相同方法。
- RealMLP-inspired 研究输入缩放、NTP、SELU 和稳健预处理，是小型任务适配，不是完整复刻原论文 benchmark。
- Muon 只更新符合规则的隐藏二维矩阵，其他参数用辅助 AdamW。EMA 在优化器更新后平均同一轨迹；不平均独立训练模型的权重。

新方法是否有效，以共同三折实测结果为准。无提升的结果也保留。注册名称只是标识，真实学习率取自 `config.lr`，不能凭名称中的 `lr0003` 猜测。

## 三种数据用途必须分开

研究阶段只用官方 train。各方法共用题目级三折，外折用于比较，内层另划早停集。标准化、median/IQR 和裁剪都只在当前拟合部分确定，外折标签不决定 epoch。

基础种子为 3036900957；额外 3036900958、3036900959 只检查稳定性，不能挑最好种子部署。外折日志里的“基础种子加折号”是固定偏移，不等于另选种子。最终完整 train 拟合仍用规定基础种子。

关闭研究后，最多确认两个已锁定新候选，按预注册规则与历史 V2 比较。不满足替换条件就保留旧模型，不能因不满意验证成绩而重开搜索。唯一方法通过导出、接口、资源、审查和新环境复现后才冻结。正式 test 只运行一次完整流程，结果只用于报告和提交，不反馈调参。

历史 V1 测试汇总和历史 V2 验证结果早已已知，必须公开这一限制，不能声称整个研究从未见过留出反馈。CV 或 validation 也不能证明当前排行榜名次。

## 表里的数字如何理解

完整题集、hard 子集和单正例子集分开报告。Hard 指至少两个不同可解析答案组；它与完整集不是同一个总体。折间样本标准差描述划分变化，固定种子标准差描述初始化敏感性，两者都不是置信区间。配对 bootstrap 对相同题目共同重采样；由于 OOF 参与选模，区间仍有选择偏差。

已完成内外层拟合时间，与包含启动、失败尝试和恢复的进程墙钟范围不同，不能相加重复计时，也不能猜测未捕获的崩溃时间。融合复用成员训练，成员只计一次；被拒绝的融合不虚构正式推理耗时。

置信度是最终实际选中答案组的概率，不一定等于组分布最大值。唯一模型选定后，用 train OOF 正确事件拟合固定 C=1 一维 logistic 映射，拟合数据指标必须标记“样本内”。验证仅检查已保存映射。校准不改答案、不被正式 predict 加载，属于可选分析资产；若将来推理使用，则必须计入推理资产。

十个等宽 ECE bin 均保留样本数，包括空 bin。Risk-coverage 表示按置信度保留题目时的累计错误率，AURC 使用保存的离散定义，不能换积分或平分规则。
