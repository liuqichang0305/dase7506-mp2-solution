# MP2 peer-review evidence template - not a completed review

No reproduced score is present. Complete only after the instructor actually
opens the MP2 process and one exact public submission is reproduced.

| Required record | Actual evidence to supply |
|---|---|
| Instructor opening and closing times | Notice URL, retrieval time, exact applicable window |
| Target submission | Course submission number, author, Issue URL |
| Immutable method | Exact commit, source URL and checked hashes |
| Matching assets | Checkpoint/configuration URL, every asset hash and byte count |
| Environment | OS, CPU, RAM, Python and actual package versions |
| Source review | Input/reference isolation, offline behavior, dependencies and asset loading |
| Installation | Exact commands, stdout/stderr, failures and any declared compatibility changes |
| Prediction | Unmodified official command, process exit and output hash |
| Independent scoring | Unmodified official command, raw official JSON and count/denominator |
| Resource measurement | Fresh prediction plus scoring wall time, thread limits, hardware qualification |
| Comparison | Submitted versus reproduced aggregate; evidence-based explanation of any difference |
| Official report generation | Current form/handler snapshot and exact generated title/body hashes |
| Actual submission receipt | Report Issue URL, number, personal author, timestamp and processing state |

Use factual observations. Package installation failure is not a zero score.
Local hardware time is not reference-machine certification. AI assistance and
the limits of the review must be disclosed; the instructor decides validity.
